# 🛠️ Daily Utility Toolbox (v2.0)

თანამედროვე, სუფთა, ოფლაინ სამუშაო ხელსაწყოების ნაკრები ყოველდღიური გამოყენებისთვის (არ საჭიროებს ინსტალაციას ან სერვერს).

## 🚀 ფუნქციონალი

1. **🔐 უსაფრთხო პაროლები & დამახსოვრებადი ფრაზები (Password & Passphrase)**
   - შემთხვევითი სიმბოლოების გენერაცია (დიდი/პატარა ასოები, ციფრები, სიმბოლოები, ორაზროვანი სიმბოლოების გამორიცხვა)
   - **დამახსოვრებადი ფრაზების გენერატორი (Passphrase)**: 3-8 სიტყვიანი კომბინაციები მორგებადი გამყოფით (`-`, `_`, `.`) და ციფრებით
   - უსაფრთხოების სიძლიერისა და ენტროპიის რეალურ დროში გამოთვლა (Bits of entropy)
   - სწრაფი მალსახმობი: `Space` კლავიში ახალი პაროლისთვის

2. **📱 QR კოდების სტუდია (QR Code Generator)**
   - ბმულების, ტექსტებისა და Wi-Fi ქსელის პარამეტრების მომენტალური QR გენერაცია
   - ფერების და ფონის მორგება
   - მაღალი ხარისხის PNG სურათად ჩამოტვირთვა
   - 100% ოფლაინ გენერაცია

3. **📝 ტექსტის ანალიზი & კოდირება (Text Suite & Encoders)**
   - რეალურ დროში მეტრიკები: სიტყვები, სიმბოლოები (სფეისებით/გარეშე), წინადადებები, აბზაცები, კითხვის დრო
   - რეგისტრის ტრანსფორმაციები: UPPERCASE, lowercase, Title Case, Sentence case, camelCase, snake_case, kebab-case
   - ტექსტის გაწმენდა (ზედმეტი სფეისები), ხაზების დალაგება (A-Z), შებრუნება
   - **Base64 Encode / Decode** & **URL Encode / Decode**

4. **⚡ JSON სტუდია (JSON Studio)**
   - JSON-ის დაფორმატება (Prettify) და შეკუმშვა (Minify)
   - სინტაქსური ვალიდაცია რეალურ დროში და შეცდომის ზუსტი ჩვენება
   - ობიექტებისა და მასივების ელემენტების რაოდენობის აღრიცხვა

5. **🎨 ფერების სტუდია & კონტრასტი (Color Studio & Contrast)**
   - HEX, RGB და HSL ფორმატების ავტომატური სინქრონიზაცია და კონვერტაცია
   - **WCAG კონტრასტის შემოწმება**: თეთრ და შავ ფონზე წაკითხვადობის ანალიზი (AA / AAA სტანდარტები)
   - ტონალური პალიტრის ავტომატური გენერაცია ერთი კლიკით კოპირებით

## ⌨️ კლავიატურის მალსახმობები
- `1` - `5`: ტაბებს შორის სწრაფი გადართვა
- `Space` ან `R`: ახალი პაროლის გენერირება
