# 🛠️ Daily Utility Toolbox

თანამედროვე, სწრაფი და მარტივი ყოველდღიური ხელსაწყოების ნაკრები პირდაპირ ბრაუზერში გამოსაყენებლად (არ საჭიროებს ინსტალაციას ან სერვერს).

## 🚀 ფუნქციონალი

1. **🔐 უსაფრთხო პაროლების გენერატორი (Password Generator)**
   - სიგრძის რეგულირება (4-დან 64 სიმბოლომდე)
   - დიდი/პატარა ასოები, ციფრები და სიმბოლოები
   - ორაზროვანი სიმბოლოების გამორიცხვა (l, 1, I, O, 0)
   - უსაფრთხოების სიძლიერის ინდიკატორი (Entropy meter)
   - ერთი კლიკით კოპირება და მზა შაბლონები (PIN, ძლიერი პაროლი)

2. **📱 QR კოდების გენერატორი (QR Code Generator)**
   - ბმულების, ტექსტების და Wi-Fi პარამეტრების მომენტალური QR გენერაცია
   - ფერების და ზომის მორგება
   - მზა QR კოდის PNG სურათად ჩამოტვირთვა
   - მუშაობს სრულად ოფლაინ, ლოკალურად

3. **📝 ტექსტის ანალიზატორი და ფორმატირება (Text Analyzer)**
   - რეალურ დროში სტატისტიკა: სიტყვები, სიმბოლოები (სფეისებით/გარეშე), წინადადებები, აბზაცები
   - კითხვისა და საუბრის სავარაუდო დრო
   - ტექსტის ტრანსფორმაციები: UPPERCASE, lowercase, Title Case, camelCase, snake_case, kebab-case
   - ზედმეტი სფეისების გასუფთავება, ხაზების დალაგება (A-Z) და შებრუნება

## 💻 როგორ გავუშვათ

უბრალოდ გახსენით `index.html` ფაილი ნებისმიერ ბრაუზერში (Chrome, Edge, Firefox, Safari).
